# 06: 连续双眼眨眼×2 复合手势

**What to build:** 可绑定的「连续双眼眨眼×2」：短窗口内两次有效双眼眨眼脉冲 → 只发出一次 EventType。与 `ActionCooldown` 分层，避免二次脉冲被 800ms 冷却吞掉。

**Blocked by:** 05（至少要有眨眼分数可读；可同 PR）

**Status:** done

- [x] 双眼眨眼分数：`max(eyeBlinkLeft, eyeBlinkRight)`（或要求两者都过阈值，实现时选更稳的并写清）
- [x] 上升沿计数器：窗口内（建议默认 ~600–800ms，可常量）凑满 2 次 → 发出一个绑定事件
- [x] 窗口内中间脉冲 **不** 调用翻页/点击 dispatch，**不** 启动 `ActionCooldown`
- [x] 复合成功派出后走现有 `ActionCooldown`
- [x] 作为手势选择页一项（可放在眨眼相关附近）；与「单次眨左/右眼」可同时存在，绑定互斥由用户选择（文档注明：同一基础动作勿同时绑单次与连续）
- [x] 纯逻辑单测：两脉冲在窗口内触发一次；窗口外两次不合并；冷却只在成功派出后生效
