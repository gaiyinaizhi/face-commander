# ADR 0001: 右下角点击用固定屏幕坐标，而不是「移光标再点」

## Status

Accepted

## Context

阅读翻页器需要在任意前台 App 注入「右下角单击」。现有 `CURSOR_TOUCH` 只点击当前头控光标位置；阅读模式下光标默认冻结/隐藏，不能依赖用户先把头移到右下角。

可选方案：(A) 先程序化移动光标再 `CURSOR_TOUCH`；(B) 新增固定比例坐标的点击全局动作。

## Decision

采用 (B)：新增「右下角点击」全局动作，用屏幕尺寸比例（默认约 0.90×0.88）直接 `GestureDescription` 点击。上滑翻页同样不依赖光标起点，使用屏幕中部几何。

## Consequences

- 阅读翻页器与光标模式解耦；光标隐藏时仍可翻页。
- 需处理导航栏/手势条遮挡（默认略上移）。
- 绑定模型增加新事件类型，而不是复用 `CURSOR_TOUCH`。
